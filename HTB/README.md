# 🧠 Hack The Box Labs

This directory contains my personal journey through Hack The Box machines.

Here, I document machines that I consider interesting, challenging, or valuable from a learning perspective. Not every machine I complete will be included — only those that provide meaningful insights, techniques, or lessons worth revisiting.

## 📌 Purpose

- Practice and improve my offensive security skills
- Document methodologies used during exploitation
- Keep track of useful techniques, tools, and attack paths
- Build a personal knowledge base for future reference

## 🛠️ What to Expect

Each machine folder may include:

- Enumeration process
- Identified vulnerabilities
- Exploitation steps
- Privilege escalation techniques
- Notes, tips, and lessons learned

## ⚠️ Disclaimer

All activities are performed in legal environments such as Hack The Box.  
This content is strictly for educational purposes.
